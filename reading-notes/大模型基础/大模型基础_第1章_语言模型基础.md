# 《大模型基础》第 1 章 语言模型基础 · 详细梳理

> 来源：毛玉仁、高云君等《大模型基础》（开源仓库 ZJU-LLMs/Foundations-of-LLMs）
> 本章主线：**语言是概率的 → 语言模型 = 预测语言符号概率的模型 → 三代建模范式（统计 → RNN → Transformer）→ 如何解码成文本 → 如何评测**

## 0. 本章导论：为什么语言模型是"概率"问题

- 语言符号在音韵、词法、句法约束下构成并承载语义，且**同样语义可有不同表达，同样符号在不同语境语义不同** → 语言本质上是概率的。
- **语言模型（LM）的目标：准确预测语言符号的概率。**
- 历史脉络：ELIZA（规则）→ 统计模型 → 神经网络模型 → GPT-4，从机械问答成长为多任务智能。
- 本章结构对应一条演进线：

```
统计 n-grams  →  RNN  →  Transformer  →  解码（采样） →  评测
(怎么算概率)    (怎么学)   (怎么并行地学)   (怎么变成文本)  (怎么衡量好坏)
```

## 1. 基于统计方法的语言模型（1.1 节）

### 1.1 n-grams 的计算方法（1.1.1）

**n-gram**：长度为 n 的词序列。n-grams 语言模型用 n-gram 与 (n-1)-gram 在语料库中的**相对频率**计算文本概率：

$$P_{n\text{-grams}}(w_{1:N}) = \prod_{i=n}^{N} \frac{C(w_{i-n+1:i})}{C(w_{i-n+1:i-1})}$$

- n=1：unigram（不考虑上下文）；n=2：bigram（只看前一个词）；n=3：trigram；以此类推。

**书中示例（长颈鹿语料库）**：

- bigram 计算 P(长颈鹿, 脖子, 长) = C(长颈鹿,脖子)/C(长颈鹿) × C(脖子,长)/C(脖子) = 2/5 × 2/6 = 2/15
- 关键观察：该句**未在语料中直接出现**，bigram 仍能给出概率 → 统计模型对未知文本有**泛化能力**（相对规则方法的优势）。
- 但 trigram 计算同一句出现**零概率**（C(长颈鹿,脖子,长)=0） → 泛化能力随 n 增大而减弱。

> **核心权衡**：n 是"拟合语料库的能力"与"对未知文本的泛化能力"之间的权衡。
> 
> - n 太大：语料中找不到完全一样的长序列 → 大量零概率
> - n 太小：承载的语言信息不足
> - 零概率可用**平滑（Smoothing）**技术缓解（书指向 Jurafsky 教材）。

### 1.2 n-grams 的统计学原理（1.1.2）

n-grams 本质 = **n 阶马尔可夫假设 + 离散型随机变量的极大似然估计**。

**定义 1.1（n 阶马尔可夫假设）**：当前状态只与前 n 个状态有关：

$$P(w_N \mid w_1, ..., w_{N-1}) \approx P(w_N \mid w_{N-n}, ..., w_{N-1})$$

**定义 1.2（离散型随机变量的极大似然估计）**：找参数 θ 使似然函数 L(θ|x) = ∏p(xᵢ; θ) 最大。

**推导链条**：

1. 链式法则：P(w₁:N) = ∏ᵢ P(wᵢ | w₁:ᵢ₋₁)
2. 用马尔可夫假设近似条件依赖：P(wᵢ|w₁:ᵢ₋₁) ≈ P(wᵢ|wᵢ₋ₙ:ᵢ₋₁)
3. 用极大似然估计近似概率：P(wᵢ|wᵢ₋ₙ:ᵢ₋₁) ≈ C(wᵢ₋ₙ:ᵢ) / C(wᵢ₋ₙ:ᵢ₋₁)
4. 结论：P_n-grams(w₁:N) ≈ P(w₁:N)

书中用 bigram 完整推导了这一点：构造对数似然 + 约束 Σⱼ P(wⱼ|wᵢ)=1，拉格朗日求导后得 P(wⱼ|wᵢ) = C(wᵢ,wⱼ)/C(wᵢ) —— **即"数频次的公式"竟然是约束优化下极大似然的解析解**。

> **关联①（本章最重要的暗线）**：链式法则 P(w₁:N)=∏P(wᵢ|w₁:ᵢ₋₁) 是全章公式的总源头。
> 它在 1.2.2 节变成 RNN 的 ∏oᵢ[wᵢ₊₁]（式 1.27），在 1.3.2 节变成 Transformer 的同形式（式 1.37），在 1.4 节又变成解码目标 P(w_{N+1:N+M})（式 1.40）。**模型架构在变，但"逐词条件概率连乘"的骨架始终不变。**

## 2. 基于 RNN 的语言模型（1.2 节）

### 2.1 RNN 的基本原理（1.2.1）

- **前馈网络（FNN）**：计算逐层向前不走回头路，当前输出只依赖当前输入：oₜ = f(W_O·g(W_I·xₜ))。
- **循环网络（RNN）**：某层计算结果经环路反向引回前面的层，形成"螺旋式前进"：

$$h_t = g(W_H h_{t-1} + W_I x_t), \qquad o_t = f(W_O h_t)$$

沿时间展开：hₜ 依赖 hₜ₋₁，hₜ₋₁ 依赖 hₜ₋₂……历史被**循环编码进隐状态**。

**例子**：预测"脖子"的下一个词，FNN 只看"脖子"（可能接"短""疼"）；RNN 同时考虑了"长颈鹿"，预测"长"概率更高 → 历史信息提升预测。

**RNN 的阿喀琉斯之踵：梯度消失/爆炸**

- 训练损失 L = Σᵢ l(oᵢ, yᵢ)，对 W_H 求梯度时含大量矩阵级联相乘：∂hₜ/∂hᵢ = ∏ ∂hₖ/∂hₖ₋₁。
- 文献结论：W_H 最大特征值 <1 → 梯度消失；>1 → 梯度爆炸 → 训练困难。
- **解决方案：门控结构** → GRU、LSTM 成为主流 RNN 架构。

### 2.2 基于 RNN 的语言模型（1.2.2）

建模方式：

$$P(w_{i+1} \mid w_{1:i}) = P(w_{i+1} \mid w_i, h_{i-1})$$

- 输出是 |D| 维向量，每维对应词典中一个词的概率；P(w₁:N) = ∏ oᵢ[wᵢ₊₁]。
- **损失函数：交叉熵** l_CE(oᵢ) = −log oᵢ[wᵢ₊₁]，训练集上取平均（式 1.30）。

**自回归（Auto-regressive）生成**：第一轮输入首词→解码出词→拼接回输入→再预测，循环迭代生成文本。

**自回归的两个问题 → 引出 Teacher Forcing → 又引出曝光偏差**（本节的概念因果链）：

| 问题        | 后果                         | 对策                                                    |
| --------- | -------------------------- | ----------------------------------------------------- |
| ① 错误级联放大  | 用模型自己生成的（可能有错的）词做输入，错误不断放大 | **Teacher Forcing**：每轮把输出与标准答案（Ground Truth）拼接作为下一轮输入 |
| ② 串行计算效率低 | 下一个词依赖上一次预测，无法并行           | （Transformer 才解决，见 3.3）                               |

- **Teacher Forcing 的副作用：曝光偏差（Exposure Bias）**——训练时总依赖"标准答案"，推理时却没有答案可参考，训练/推理分布不一致 → 推理效果差。
- **对策：Scheduled Sampling**（Bengio 等）：训练中循序渐进地用一小部分模型自己生成的词替代标准答案，对"无答案"的推理场景提前预演。

> **关联②**：RNN 的"循环迭代本质 → 不易并行 → 长序列训练慢"正是 1.3 节引入 Transformer 的直接动机（原书末尾明确点出）。**RNN 用"串行循环"编码历史，Transformer 改用"一次输入全部历史+加权"**。

## 3. 基于 Transformer 的语言模型（1.3 节）

### 3.1 Transformer 结构（1.3.1）

Transformer = 两类模块堆叠：

1. **注意力模块** = 自注意力层 + 残差连接 + 层正则化
2. **全连接前馈模块** = 前馈层 + 残差连接 + 层正则化

**① 自注意力层**：加权平均思想——把输入编码为 query/key/value：

$$q_i = W_q x_i,\quad k_i = W_k x_i,\quad v_i = W_v x_i$$
$$\alpha_{t,i} = \text{softmax}(\text{sim}(q_t, k_i)), \qquad \text{Attention}(x_t) = \sum_{i=1}^{t} \alpha_{t,i} v_i$$

- query 和 key 算权重 α，value 是被编码的输入内容。**相比 RNN 的"逐个串行累积"，注意力是"通盘考虑后加权求和"**。

**② 全连接前馈层**（占 Transformer 约 2/3 参数，被视为模型的"记忆"）：

$$\text{FFN}(v) = \max(0, W_1 v + b_1) W_2 + b_2$$

两层之间 ReLU；可解读为 Key-Value 记忆模式：第一层≈key，第二层≈value。

**③ 层正则化（LayerNorm）**：LN(vᵢ) = α(vᵢ−μ)/δ + β，逐维度归一化，加速训练、提升泛化。

**④ 残差连接**：把层输入经旁路叠加到输出，缓解梯度消失。

**Post-LN vs Pre-LN**：

- Post-LN（LN 在残差之后）：抗表征坍塌更强，抗梯度消失较弱
- Pre-LN（LN 在残差之前）：抗梯度消失更好，抗表征坍塌较弱

**整体架构（原始 Transformer）**：Encoder 6 层（每层 1 注意力 + 1 前馈，自注意力），Decoder 6 层（每层 2 注意力 + 1 前馈，第一个是自注意力、第二个是交叉注意力——query 来自 Decoder、key/value 来自 Encoder 输出）。

- Encoder / Decoder 可单独使用 → **Encoder-Only（如 BERT）与 Decoder-Only（如 GPT）**，第二章详解。

### 3.2 基于 Transformer 的语言模型（1.3.2）

**三种预训练任务对应三类模型**（与第 2 章的衔接点）：

| 用到的部分           | 预训练任务      | 代表模型  |
| --------------- | ---------- | ----- |
| Encoder         | 掩词补全       | BERT  |
| Encoder+Decoder | 截断补全、顺序恢复等 | T5    |
| Decoder         | 下一词预测      | GPT-3 |

训练流程与 RNN LM 完全同构（呼应关联①）：P(w₁:N)=∏oᵢ[wᵢ₊₁]，交叉熵损失，反向传播训练；预训练同样用 **Teacher Forcing**。

**Transformer vs RNN 的根本对比**：

|        | RNN         | Transformer                       |
| ------ | ----------- | --------------------------------- |
| 历史信息处理 | 沿时间循环累积（串行） | 全部历史同时输入、加权求和（并行）                 |
| 并行性    | 差           | 好                                 |
| 代价     | 长程依赖难、梯度问题  | 模型规模随序列长度**平方增长** → 长序列挑战（第 2 章续） |

## 4. 语言模型的采样/解码方法（1.4 节）

LM 输出是概率向量，自回归逐轮生成向量后要**解码为文本**。两大类方法：

### 4.1 概率最大化方法（1.4.1）

目标：最大化 P(w_{N+1:N+M}) = ∏ oᵢ[wᵢ₊₁]。搜索空间 M^|D|，**NP-Hard**，只能启发式搜索。

**① 贪心搜索**：每轮选概率最大的词（argmax）。

- 缺陷：只顾眼前、易陷局部最优。书中例："是"(0.3) → "是草食"(0.03)，不如"脖子"(0.2) → "脖子长"(0.1)。

**② 波束搜索（Beam Search）**：每轮保留 b 个概率最高的候选词，结束后在所有候选组合中找联合概率最大者。

- b=2 的例子能得到"脖子长"(0.1)，优于贪心的"是草食"(0.03)。

**共同缺陷**：概率最大的文本往往是最常见、最平庸的文本 → 开放式生成中容易产生**重复、缺乏多样性的"废话文学"** → 需要引入随机性。

### 4.2 随机采样方法（1.4.2）

每轮先选候选词集，再按归一化概率分布随机采样。

**① Top-K 采样**：保留概率最高的 K 个词，softmax 归一化后采样。

- 问题：K 固定，各轮分布形态不同——
  - 分布方差大 → 候选集混进小概率词 → **"胡言乱语"**（如"长颈鹿有四条裤子"）
  - 分布方差小（接近均匀）→ K 容纳不下更多相近概率词 → **"枯燥无趣"**（漏掉"打架""睡觉"等新颖用法）

**② Top-P 采样（Nucleus 采样）**：不按固定个数、改按**概率阈值 p** 选候选集：取累计概率 ≥ p 的最小词集。

- 自适应大小：避免小概率怪词（治胡言乱语），又能容纳大批相近概率词（治枯燥）。

**③ Temperature 机制**：对 softmax 自变量除以 T，调节随机性：

- T > 1：分布更平坦 → 随机性增强（适合开放创作）
- 0 < T < 1：强者越强 → 随机性减弱（适合代码生成等保守场景）

> **关联③**：解码方法是一条"对症下药"的演进链——
> **贪心（局部最优）→ 波束（缓解局部最优但平庸）→ 随机采样（加多样性）→ Top-K（候选集固定引入新问题）→ Top-P（自适应候选集）→ Temperature（按需调随机性）**。每一步都是对上一步缺陷的修补。

## 5. 语言模型的评测（1.5 节）

两大类：**内在评测**（不看任务，直接评生成能力）与**外在评测**（放到具体任务上评）。

### 5.1 内在评测：困惑度 Perplexity（1.5.1）

$$PPL(s_{test}) = P(w_{1:N})^{-1/N} = \sqrt[N]{\prod_{i=1}^{N} \frac{1}{P(w_i \mid w_{<i})}}$$

- 测试文本与预训练文本独立同分布；模型对测试文本越"肯定"（概率越高）→ PPL 越小 → 生成能力越好。
- 等价改写：PPL = exp(−1/N · Σ log P(wᵢ|w<ᵢ))，指数部分正是**生成分布与真实分布的交叉熵**。
- 进一步：交叉熵是信息熵的上界 → **PPL 下降 ⇒ 熵减 ⇒ 模型"胡言乱语"的可能性降低**。

> **关联④**：PPL 的指数形式把第 1~3 节的训练目标（交叉熵，式 1.29/1.38）和评测指标焊在了一起——**训练就是在最小化平均 log 损失，评测就是在对它取指数**。最小化交叉熵 ⟺ 最小化困惑度。

### 5.2 外在评测（1.5.2）

测试文本 = 任务上的问题 + 标准答案。分两类方法：

**① 基于统计指标**

| 指标    | 导向  | 任务   | 核心思想                                                                       |
| ----- | --- | ---- | -------------------------------------------------------------------------- |
| BLEU  | 精度  | 机器翻译 | 多层次 n-gram 精度的几何平均；可加权重/长度惩罚                                               |
| ROUGE | 召回  | 摘要生成 | ROUGE-N（n-gram 召回）、ROUGE-L（最长公共子序列召回）、ROUGE-W（加权 LCS）、ROUGE-S（Skip-bigram） |

BLEU 例：生成"big language models"，参考"large language models" → unigram 精度 2/3，bigram 精度 1/2。

- 共性缺陷：只看字面重叠，**无法适应表达的多样性**，与人类评测差距大，尤其在生成内容有创造性时。

**② 基于语言模型的评测（用模型当"裁判"）**

| 方法            | 基础          | 是否需要参考答案 | 特点                                                                                                  |
| ------------- | ----------- | -------- | --------------------------------------------------------------------------------------------------- |
| BERTScore     | BERT 上下文词嵌入 | 需要       | 对生成/参考文本的词嵌入算 Precision/Recall/F1（余弦相似度取 max 匹配），比统计指标更接近人类评测                                       |
| G-EVAL        | GPT-4 生成    | **不需要**  | 用 Prompt 工程引导 GPT-4 打分：Prompt 三段 = 任务描述与评分标准 + GPT-4 自生成的 CoT 评测步骤 + 输入与生成文本；再加"对所有可能得分加权平均"解决区分度不足 |
| InstructScore | 生成模型        | 不需要      | 除分数外还给解释（可解释性更强）                                                                                    |

> **关联⑤**：评测方法的演进（统计重叠 → 语义嵌入 → 生成式裁判）呼应了全章的模型演进——**LM 越强，越能反过来当评测者**；同时 G-EVAL 用到的 Prompt 工程与思维链正是第 3 章的内容，BERT 与 BERTScore 依赖的上下文词嵌入在第 2 章展开。

| 极大似然估计                  | 选使观测数据似然最大的参数；n-grams 的频次公式即其解析解      |
